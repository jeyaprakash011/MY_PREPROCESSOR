

# my_Preprocessor

A custom preprocessor implemented in C to understand how the C preprocessor works before compilation.

## Features

* Single-line macro replacement
* Multi-line macro replacement
* Header file inclusion
* Object-type macro replacement
* `#define` directive processing
* Source code preprocessing

## Technologies Used

* C Programming
* File Handling
* Pointers
* Strings
* C Preprocessor Concepts

## Project Objective

The main objective of this project is to implement basic C preprocessing operations from scratch and understand how source code is modified before it reaches the compiler.

## How It Works

The preprocessor reads the input C source file, identifies supported preprocessing directives, performs the required replacements or inclusions, and generates the preprocessed output.

* File handling
